# Manohar Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Run locally

1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## Files

- `index.html` — portfolio structure/content
- `style.css` — design, responsiveness and animations
- `script.js` — menu, reveal animations and cursor glow
- `assets/` — uploaded portfolio photos
- `Manohar_Resume.pdf` — resume download
