MANOHAR PORTFOLIO

Folder structure:
  index.html
  certificates/
      (certificate PDF/JPEG files)

Important:
- Keep the certificates folder beside index.html.
- Open index.html in a browser, or use VS Code Live Server.
- Clicking a certification opens it in the built-in certificate viewer.
- PDF certificates are displayed in an iframe.
- JPEG certificates are displayed as images.
- Replace the GitHub # links with your actual GitHub profile/repository URLs.
- Replace the phone placeholder before publishing.
